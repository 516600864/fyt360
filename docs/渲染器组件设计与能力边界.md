# FYT360 渲染器组件设计与能力边界（27 组件全量）

> 2026-09-29 定稿。Schema 引擎（page-v1）楼层组件 = C 端渲染器（packages/renderer，小程序/H5 双端同稿）与后台装修器（DIY/AI 页共用 FloorPreview 预览 + DiyEditor 属性面板）两侧对齐。
> 通用约定：楼层=JSON（type + floor_id + props [+ data_source]）；主题只读 `var(--fyt-*)`；点击动作统一 Action 协议。

## 一、Action 协议（通用点击动作）

| type | 行为 | 说明 |
|------|------|------|
| `none` | 不可点 | 默认 |
| `jump/page` | 端内 navigateTo | value=页面路径，如 `/pages/goods/search-result`；目标页不存在时诚实 toast |
| `jump/h5` | 小程序 webview / H5 直跳 | value=链接 |
| `jump/weapp` | 跳其他小程序 | value=appId，params.path=内页路径 |
| `plugin-launch` | 品牌呼起蚂蚁星球 | value=brand_code，服务端 brand-launch 下发半屏/插件/H5 链接 |
| `activity` | 活动页（数据面未建） | 诚实 toast「活动页建设中」 |
| `popup` | 端内半屏弹层 | value=文案，渲染器内置弹层，不上抛宿主 |

支持楼层级 action 的组件：search-bar（胶囊）、coupon-strip、rich-text、ingot-entry、float-btn、member-card、invite-floor、popup-modal、floor（整卡）。支持 item 级 action 的组件：swiper（每帧）、nav（每入口）、category-nav（每分类）、brand-matrix（每格）、activity-floor（每按钮）、image-hotzone（每热区）、seckill/group-buy-floor/coupon-wall（每项）。

## 二、基础组件（9）

### 1. search-bar 搜索栏
- **设计**：券 logo + 搜索占位 + 鎏金胶囊（画布 mini-01①）。
- **可配**：logo 文案、placeholder、胶囊文案、胶囊 action；搜索框动作独立（search_action，默认跳 07B 全站搜索页）。
- **边界**：搜索框与胶囊是两个独立点击位；首页搜索条落点=07B（全站），07（CPS 平台专属）由 07B 内「一键搜券」进入——先全站再专属。

### 2. swiper 轮播图
- **可配**：自动轮播/间隔；每帧：图片上传（≤3MB）、主标题、强调词、标签、尾部文案、emoji、三款波普渐变、帧级 action。
- **边界**：设图后配色/emoji 不展示（图优先）；无图时为纯渐变文字卡。

### 3. nav 金刚区
- **可配**：每行 3~5 列；每入口：icon（emoji）、名称、入口级 action。
- **边界**：最多渲染 10 个入口（超出截断）。

### 4. notice 公告栏
- **可配**：多行公告（每行一条）。
- **边界**：单条超长省略号截断；无轮播滚动动画（后续可加）。

### 5. divider 标题分隔
- **可配**：标题、副标题。

### 6. blank 间距
- **可配**：高度 8~200rpx。

### 7. floor 通用容器
- **可配**：标题、副标题、正文、背景（4 款）、**整卡 action**（2026-09-29 补，此前纯展示）。
- **边界**：容器内**不放其他组件**（不做嵌套布局引擎）——需要组合内容用多楼层堆叠。

### 8. category-nav 分类导航
- **可配**：横向 chips 列表：分类名、hot 高亮、逐项 action。
- **边界**：横滑单行；无二级分类。

### 9. rich-text 图文说明
- **可配**：标题、角标、多段落文本、更多文案、楼层 action。
- **边界**：纯文字段落（无富文本标签解析/内嵌图）——图用 image-hotzone/activity-floor。

## 三、营销组件（11）

### 10. coupon-strip 优惠券条
- **可配**：面额、上下备注、按钮文案、楼层 action；**从营销券库选券**（快照内联，端上不回源）。
- **边界**：券数据=发布时快照；营销中心改券不自动同步楼层。

### 11. seckill 限时秒杀
- **可配**：标题、更多文案、截止时间（到点倒计时）、商品项（图上传/名/秒杀价/划线价/项级 action）。
- **边界**：**装修器配置数据驱动，不接秒杀交易数据面**（秒杀下单未建）；未配 action 的项点击无交易行为，诚实空转。

### 12. activity-floor 活动楼层
- **可配**：标题、副标题、背景图上传（设图后配色不展示）、背景配色、按钮组（文案/幽灵样式/按钮级 action）。

### 13. brand-matrix 品牌宫格
- **可配**：每行 2~5 列；每格：icon、名称、角标、格级 action（典型=plugin-launch 品牌呼起）。

### 14. image-hotzone 图片热区
- **可配**：底图上传；热区列表（x/y/宽/高 百分比 + 热区级 action）。
- **边界**：热区定位按百分比，适配任意宽度；不可视化拖拽（数值编辑，后续可加可视化）。

### 15. countdown 倒计时
- **可配**：标题、备注、截止时间、到期文案。
- **边界**：纯倒计时展示，不触发开抢逻辑（与 seckill 独立）。

### 16. popup-modal 进页弹窗
- **可配**：标题、内容、弹窗图、按钮文案、进页自动弹开关、楼层 action。
- **边界**：关闭后同一次会话不再弹（storage 记忆）；每页多弹窗时依次出。

### 17. float-btn 悬浮按钮
- **可配**：文案、icon、距底部距离、楼层 action。

### 18. video-floor 视频楼层
- **可配**：标题、视频 mp4 URL、封面图上传。
- **边界**：视频文件传静态托管后贴直链；不支持选集/弹幕。

### 19. group-buy-floor 拼团楼层
- **可配**：标题、副标题、商品项（图/名/拼团价/划线价/已拼文案/项级 action）。
- **边界**：**装修器配置数据驱动，不接拼团交易数据面**（拼团下单/核销链路未建）；「去拼团」未配 action 时诚实空转。

### 20. coupon-wall 券墙中心
- **可配**：标题、副标题、券列表（名/面额/条件/按钮文案/项级 action）。
- **边界**：配置数据驱动，不联动营销券库存量与领取状态（无「已领取」追踪）。

## 四、业务组件（7）

### 21. brand-chips 品牌补贴日
- **可配**：标题、角标、chips（手编逗号串或**从品牌库选择** 159 品牌，产出 {label,value}）。
- **边界**：chips 点击动作=组件内置品牌呼起协议（value=brand_code），不逐项自定义。

### 22. goods-feed 商品流
- **数据源二选一**：
  - `platform_tab`：CPS 平台（jd/tb/pdd/vip 勾选），**实时透传不落库**（铁律：CPS 无选品）；页大小可配。
  - `self`：到店团购商品库选品（唯一有选品的模式，goods_ids 快照 + 大图/两列布局 + 团购挂标）。
- **端内行为**：商品点击统一协议——到店团购→小程序 self-detail（H5 端呼起小程序 URL Scheme）；CPS→商详页（mini-03/H5 同稿）→领券购买转链。
- **边界**：CPS 无选品无手动排序；团购已选商品下架后楼层如实减员。

### 23. ingot-entry 元宝入口
- **可配**：标题、副标题、按钮文案、楼层 action（默认跳元宝页）。

### 24. movie-box 影票热映
- **可配**：热门/即将上映模式、标题与更多文案覆盖、呼起品牌码。
- **边界**：**小程序端渲染 mayi-movie 插件真实购票列表；H5/admin 预览为占位卡**（插件无 H5 运行时，诚实呈现）。

### 25. redeem-entry 权益直达
- **可配**：**从蚂蚁 fasttype 实时权益列表选 cid**（搜索选择，非手填）、标题、副标题、按钮、emoji、呼起品牌码。
- **端内行为**：点击=brand-launch 呼起蚂蚁星球兑换弹窗（半屏），仅小程序端；H5 端跳生活服务分类。
- **边界**：蚂蚁积分与我方元宝零关系（展示文案用「元宝」仅口径提示）；权益实时价格不落库。

### 26. member-card 会员权益卡
- **可配**：标题、副标题、等级标签、按钮文案、背景、楼层 action。
- **边界**：等级标签为静态文案，不读用户真实等级（个性化请用「我的」页）。

### 27. invite-floor 邀请有礼
- **可配**：标题、说明、奖励文案、按钮文案、楼层 action。
- **边界**：按钮默认跳邀请页；邀请返佣数据不在楼层内展示。

## 五、双端与预览的诚实口径

| 面 | 说明 |
|----|------|
| 小程序 | 27 组件全实现；movie-box/redeem-entry 的呼起依赖微信运行时 |
| H5 | 27 组件全实现；到店团购交易=呼起小程序（URL Scheme，**需小程序正式发布后生效**，当前 40165 诚实提示）；movie-box 占位卡 |
| admin 预览 | FloorPreview 近似 mock（27 类型全对齐），非真实数据渲染 |
| 校验 | server page-validate：27 类型白名单、≤30 层、action 枚举收窄；props 结构不收窄（组件自身容错） |

**AI 建页**：27 种组件均在产出白名单内，非法输出 ajv 校验失败自动重试 ≤2 次；生成结果存 AI 草稿 → 页面装修微调 → 发布双端生效，llm_log 全程留痕可回滚。
